## 🚀 安装

### 宝塔面板（推荐）

| 步骤 | 操作 |
|---|---|
| 1️⃣ 建站 | 宝塔 → 添加站点（PHP 7.4+）+ 创建 MySQL 数据库 |
| 2️⃣ 上传 | 发行包解压到站点根目录（`index.php` 在根级） |
| 3️⃣ 安装 | 访问域名 → 安装向导填数据库信息 → 完成 |
| 4️⃣ 收藏后台 | 安装完成页展示随机入口（`admin_xxxx.php`，**只显示一次**） |
| 5️⃣ 加固 | 删除 `install.php`；Nginx 加 `location ^~ /data/ { deny all; }` |

**最后一步别漏掉** —— 添加每分钟计划任务（订单超时关闭 + 链上到账轮询）：

```bash
php /www/wwwroot/你的站点目录/cron.php
```

### Docker

```bash
docker compose up -d --build
# 访问 http://IP:8080/install.php
# 数据库: 地址 db / 库名 kunfaka / 用户 kunfaka / 密码 kunfaka123
```

自带 cron 服务，数据存命名卷，升级镜像不丢配置。

## ❓ FAQ

<details>
<summary><b>忘了后台入口怎么办？</b></summary>
查看 <code>data/config.php</code> 里的 <code>YF_ADMIN_ENTRY</code>，就是入口文件名。
</details>

<details>
<summary><b>USDT 显示未到账？</b></summary>
地址必须 TRC20（T 开头）、金额与页面完全一致、cron 计划任务已配置。
</details>

<details>
<summary><b>支付回调失败？</b></summary>
系统设置的「网站地址」填完整 https 域名，确保公网可达。
</details>

<details>
<summary><b>验证码组件不显示？</b></summary>
极验 ID/Key 别填反，极验后台域名白名单加上你的域名；密钥不全时系统自动降级为图形码。
</details>

<details>
<summary><b>能自己开发插件 / 主题吗？</b></summary>
能。插件放 <code>plugins/</code>，主题复制 <code>themes/store</code> 改 CSS，商店机制自动识别。
</details>
