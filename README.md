## 📖 程序介绍

坤发卡是一套面向个人站长与小型团队**全自动发卡系统**: 买家在网站选好商品、扫码付款, 系统在支付成功的瞬间自动完成发货——卡密直接显示在买家屏幕上, 同时发送一封含卡密的邮件到买家邮箱。全过程无需人工介入, 7×24 小时不间断营业。

它适合售卖一切「付款后可自动交付」的商品:

- **虚拟物品**: 游戏充值、点卡、CDK、会员开通码、软件激活码、课程兑换码
- **账号服务**: 账号租售、代充服务、会员充值
- **实物商品**: 支持收件人姓名 + 邮寄地址字段, 买家下单时填写收货信息

**几个核心设计原则:**

- **程序完全免费开源(MIT)**: 商品、卡密、订单、会员、支付、主题机制、应用商店机制全部无限制, 核心功能永不加付费墙
- **部署零门槛**: 无 Composer、无 Node 编译, 宝塔面板跟着向导点下一步即可; 也提供 Docker Compose 一键部署
- **安全默认开启**: CSRF 全站令牌、支付回调双验签、随机后台入口、人机验证、防爆破锁定, 装好即是安全态
- **扩展走商店**: 内置应用商店(插件/主题), 在线安装、在线升级; 开发者按目录规范即可接入自有插件与主题

## 🔧 安装教程

### 方式一: 宝塔面板(推荐)

1. **添加站点**: 宝塔 → 网站 → 添加站点, 填写域名, PHP 选择 7.4 及以上, 勾选创建 MySQL 数据库并记下密码
2. **上传程序**: 将发行包(zip)上传到站点根目录并解压——`index.php` 必须直接位于根级
3. **运行安装向导**: 浏览器访问你的域名, 自动跳转安装页, 填入数据库地址/库名/用户名/密码, 设置管理员账号密码
4. **收藏后台入口**: 安装完成页会展示**随机安全入口**(形如 `admin_x7k9q2.php`), 只显示这一次, 务必立即收藏
   > 忘了入口? 查看 `data/config.php` 中的 `YF_ADMIN_ENTRY`, 对应文件名就是入口
5. **安全收尾**: 删除根目录的 `install.php`; Nginx 用户在站点配置中加入:

```nginx
location ^~ /data/ { deny all; }
```

6. **配置计划任务**(重要, 缺失会影响 USDT 到账与订单关闭): 宝塔 → 计划任务 → Shell 脚本, 每 1 分钟执行:

```bash
php /www/wwwroot/你的站点目录/cron.php
```

### 方式二: Docker Compose

```bash
docker compose up -d --build
```

访问 `http://服务器IP:8080/install.php` 完成安装, 数据库信息: 地址 `db`、库名 `kunfaka`、用户 `kunfaka`、密码 `kunfaka123`。

- 自带 cron 服务(订单过期 + 链上轮询), 无需额外配置计划任务
- 配置与上传图片保存在命名卷 `app_data` / `app_uploads`, 升级镜像不丢失
- 改端口: 编辑 `docker-compose.yml` 中 `"8080:80"` 左侧数字
- 生产建议: 前置 Cloudflare 或 Nginx 反代做 HTTPS 后再对外

## 💳 支付插件配置详解

后台 → 应用商店 → 插件 → 安装 → 启用 → 配置。支付页会自动匹配微信/支付宝/USDT/QQ 等品牌图标。

### 1. 码支付(易支付协议, 免费个人可接)

- 到 [码支付平台](https://xpay.shw1.com/doc/epay_submit) 注册并实名, 获得商户 ID(pid) 与商户密钥(KEY)
- 插件配置填: 网关地址(默认已填)、pid、KEY、勾选支付渠道(支付宝/微信/QQ)
- 一码多渠道: 勾选多个渠道后, 前台自动展开为多个品牌支付方式

### 2. 易支付(免费)

- 填写任意易支付平台的网关地址、商户 ID、商户密钥即可

### 3. 支付宝当面付 / 支付宝官方(免费)

- 前往 [支付宝开放平台](https://open.alipay.com) 创建应用并签约「当面付」或「电脑网站支付」
- 配置填: APPID、应用私钥(PKCS8 格式)、支付宝公钥; 回调地址由系统自动生成

### 4. 微信官方支付 V3 Native(免费)

- 前往 [微信支付商户平台](https://pay.weixin.qq.com) 开通 Native 支付产品
- 配置填: 商户号、APPID(需绑定商户号)、API 证书序列号、`apiclient_key.pem` 私钥内容、APIv3 密钥

### 5. Stripe 国际信用卡(免费)

- [Stripe 后台](https://stripe.com) 获取 API 密钥填入; Webhook 异步通知 + 回跳二次核实双通道发货

### 6. 加密币免挂支付系列 ⭐ 专业版

| 插件 | 你需要准备 | 到账检测 |
|---|---|---|
| USDT 免挂(TRC20) | 只填 TRC20 收款地址(T 开头) | TRON 公链公开接口 |
| USDT 多链 | 对应链收款地址 + 区块浏览器免费 API 密钥 | Etherscan 系接口 |
| BTC / ETH | 收款地址(ETH 可选 Etherscan 密钥) | 各公链公开接口 |
| XMR | 自建 monero-wallet-rpc + 地址 | 钱包 RPC |
| EPUSDT 网关 | 自部署 [EPUSDT](https://epusdt.com) 的网关地址/PID/密钥 | 网关回调 |

> **免挂原理**: 下单时给每笔订单分配一个唯一金额尾数(法币计价则按实时汇率换算), 公链接口轮询到账并精准匹配金额后自动发货。无需挂机钱包、无需暴露私钥、无需节点。

### 7. 专业版与付费内容说明

- 商店中标注 ⭐ 的插件与主题为付费内容, **99 元专业版会员全部免费下载**(含后续上新)
- 付费应用经官方商店下载时按「你的站点域名 + 授权码」动态加密打包, 仅授权站点可解密运行, 文件泄露或复制到其他站点均无法使用

## ❓ 常见问题

<details>
<summary><b>忘了后台入口怎么办</b></summary>
查看站点 <code>data/config.php</code> 中的 <code>YF_ADMIN_ENTRY</code>, 对应的文件名就是后台入口。
</details>

<details>
<summary><b>页面空白或报错</b></summary>
确认 PHP ≥ 7.4 且宝塔站点设置的 PHP 版本正确; 查看 <code>data/</code> 下日志与站点 PHP 错误日志。
</details>

<details>
<summary><b>支付回调不成功</b></summary>
系统设置「网站地址」必须填完整 https 域名, 并确保公网可直接访问回调地址(经 Cloudflare 时注意回源设置)。
</details>

<details>
<summary><b>USDT 显示未到账</b></summary>
三个条件缺一不可: 收款地址为 TRC20(T 开头)、买家转账金额与页面显示完全一致、每分钟 cron 计划任务已配置。
</details>

<details>
<summary><b>微信/支付宝回调验签失败</b></summary>
支付宝公钥与应用私钥是否填反; 微信 APIv3 密钥或证书序列号是否填错。
</details>

<details>
<summary><b>人机验证按钮不显示</b></summary>
极验 ID/Key 勿填反, 且极验后台域名白名单需包含你的站点域名; 任一模式密钥不完整时系统自动降级为图形验证码, 不会锁死登录。
</details>

<details>
<summary><b>商店无法下载应用</b></summary>
检查「系统设置 → 官方市场地址」是否可访问; 付费应用需先在授权中心激活专业版。
</details>

<details>
<summary><b>能自己开发插件或主题吗</b></summary>
能。插件放入 <code>plugins/</code> 目录并附 json 元信息即可被商店识别; 主题复制 <code>themes/store</code> 修改样式, 缺失视图自动继承默认主题。
</details>
