## 二、安装步骤(3分钟)

1. **宝塔 → 网站 → 添加站点**: 域名填你的域名, PHP版本选 7.4+, 数据库选 MySQL 并记住密码。
2. **上传程序**: 把 `坤发卡.zip` 上传到站点根目录并**解压到当前目录**(解压后站点根目录下直接是 index.php 等文件)。
3. **访问域名**: 浏览器直接打开 `http://你的域名/` —— 未安装时自动跳转到安装向导
   - 第1步环境检测全部通过 → 第2步同意协议 → 第3步照抄宝塔数据库页面的信息 + 设置管理员账号密码 → 完成。
4. **收藏后台地址**: 安装完成页面会展示**随机生成的后台安全入口**(形如 `http://你的域名/admin_x7k9q2.php`), 该地址只在此时完整展示一次, 请立即收藏!
   - 原始的 `admin.php` 在安装时会被自动重命名, 旧的 `admin.php` 地址访问返回404。
   - 如果忘了后台地址: FTP查看 `data/config.php` 中的 `YF_ADMIN_ENTRY` 即可找到。
5. **安全收尾**: 删除 `install.php`; Nginx用户在宝塔站点配置中加入:

```nginx
location ^~ /data/ { deny all; }
```

## 二点五、Docker 部署(可选, 无需宝塔)

无需宝塔面板, 一条命令拉起「站点 + MySQL + 计划任务」三件套:

```bash
# 前提: 服务器已安装 Docker 与 Docker Compose 插件
docker compose up -d --build
```

然后浏览器访问 `http://服务器IP:8080/install.php` 完成安装向导, 数据库连接信息填:

| 项 | 值 |
|---|---|
| 数据库地址 | `db` |
| 数据库名 | `kunfaka` |
| 用户名 | `kunfaka` |
| 密码 | `kunfaka123` |

说明:

- compose 已自带 **cron 服务**(每分钟自动执行订单过期与链上免挂支付轮询), 无需配置计划任务;
- 配置与上传图片保存在命名卷 `app_data` / `app_uploads` 中, 升级镜像不丢失;
- 修改端口: 编辑 `docker-compose.yml` 中 `"8080:80"` 左侧端口;
- 常用命令: 查看日志 `docker compose logs -f app`; 升级 `docker compose up -d --build`; 停止 `docker compose down`(数据保留);
- 生产建议: 前置 Cloudflare 或 Nginx 反代做 HTTPS 后再对外提供服务。

## 四、配置计划任务(重要)

宝塔 → 计划任务 → 添加任务:
- 类型: **Shell脚本**, 执行周期: **每1分钟**, 脚本内容:

```bash
php /www/wwwroot/你的站点目录/cron.php
```

也可以用访问URL方式(需携带密钥, 密钥见 `data/config.php` 中的 `YF_KEY`):

```bash
curl -s "http://你的域名/cron.php?key=你的YF_KEY值"
```

作用: ① 未支付订单超时自动关闭 ② USDT免挂支付链上到账轮询(买家支付页也会自动触发检测, 配置计划任务实时性更好)。

### 人机验证(极验GeeTest / Cloudflare Turnstile / 图形验证码)
- 后台「系统设置 → 人机验证」三选一, 作用于: **前台注册、前台登录、后台登录**。
- **极验 GeeTest v4**(推荐, 一键通过体验): 到 [极验后台](https://auth.geetest.com) 创建行为验证4.0验证单元, 把 Captcha ID / Captcha Key 填入后台即可。
  - 「验证有效期(秒)」默认 **120**, 可在后台调整(10-600): 弹窗验证通过后, 超出该时限的验证结果会被服务端二次校验拒绝; 同时作为前端验证请求超时。
  - 采用bind模式: 点击登录/注册按钮弹出极验窗口, 低风险用户**一键通过**, 高风险自动升级滑块/图标等挑战, 服务端再做二次校验(签名: HMAC-SHA256)。
- **Cloudflare Turnstile**: 到 [Cloudflare Dashboard → Turnstile](https://dash.cloudflare.com/?to=/:account/turnstile) 添加站点, 填入 Site Key / Secret Key。
- 未开启上述任一验证时自动使用**内置图形验证码**(GD生成, 点击刷新); 也可整体关闭验证。
- 任一模式的密钥填写不完整时, 系统自动降级为图形验证码, 不会锁死登录。

### 安全限制(自动生效, 无需配置)
| 防护项 | 规则 |
|---|---|
| 注册IP限制 | 同一IP每24小时最多注册 **3** 个账号, 超出后需等待窗口滚动(最长24小时) |
| 登录爆破锁定 | 同一账号+IP 一天内密码错误 **5** 次 → 锁定 **60分钟**(锁定期间正确密码也无法登录) |
| IP轮换爆破兜底 | 同一IP 60分钟内累计错误 ≥20 次 → 锁定60分钟 |

### 安全设计(v1.8.0 渗透测试加固)
- **订单号高熵随机**(64位随机空间), 无法遍历枚举他人订单与卡密;
- 全站表单**CSRF防护**(前台下单/登录/注册/支付 + 后台全部操作), 外部支付回调按签名校验不受影响;
- 支付回调**双重校验**: 签名验证 + **金额与订单一致性比对**, 异常金额自动拒绝并写入日志;
- 计划任务URL方式需携带密钥 `cron.php?key=YF_KEY`(Shell方式不受限), 防止外部随意触发;
- 应用商店安装包**Zip Slip防护**, 拒绝路径穿越的恶意包; 插件类名白名单校验;
- 系统安装器防重装接管(已有管理员时拒绝重装, 即使install.lock被删);
- 自动携带安全响应头(nosniff / X-Frame-Options / Referrer-Policy)。
- 渗透测试覆盖: SQL注入/XSS反射与存储/CSRF/越权枚举/通知伪造/金额篡改/路径穿越/cron滥用/敏感文件/爆破锁定, 共32项断言全部通过。

### 2. 易支付
- 填写任意易支付平台的 网关地址/商户ID/商户密钥。

### 3. 支付宝当面付 / 支付宝官方
- [支付宝开放平台](https://open.alipay.com) 创建应用 → 签约「当面付」或「电脑网站支付」。
- 拿到: APPID、应用私钥(PKCS8)、支付宝公钥, 填入插件配置。
- 回调地址系统已自动生成, 无需手填。

### 4. 微信官方支付(V3 Native扫码)
- [微信支付商户平台](https://pay.weixin.qq.com) 开通 Native 支付产品。
- 拿到: 商户号、APPID(需与商户号绑定)、API证书序列号、`apiclient_key.pem` 私钥内容、APIv3密钥。

### 5. USDT免挂支付(TRC20) ⭐ 专业版专享
- 应用商店下载启用(需99元专业版会员)。
- 配置中只需填一项: **你的TRC20钱包地址**(以T开头)。
- 原理: 每笔订单分配唯一金额尾数, 系统通过TRON公链公开接口(TronGrid)自动识别到账并自动发货。无需挂机软件、无需节点、无需API密钥。

## 七、应用商店 & 99专业版会员

- 商店分 **插件** / **主题** 两个板块; 应用分免费和付费。
- 免费应用: 直接一键下载安装; 付费应用需先激活专业版授权码。
- 付费应用(如 USDT多链免挂支付、专业版主题): **开通99元专业版会员后免费下载**, 后续上架的新付费应用同样免费。
- 后台 → 授权中心: 粘贴授权码激活专业版(默认在线校验并绑定域名; 如需离线激活, 在 data/config.php 自定义 `YF_OFFLINE_SECRET` 密钥)。
- 官方离线授权码生成: `YF_OFFLINE_SECRET=密钥 php tools/make_license.php 10`(密钥与发卡端配置一致)。
- 想自建市场服务端(主控): 把 `license-server/` 目录内**全部文件**部署到主控域名根目录(Apache开箱即用; Nginx伪静态加一行 `if (!-e $request_filename) { rewrite ^(.*)$ /index.php?$1 last; }`)。无需MySQL(SQLite), 首次访问 `/admin` 创建管理员。
- 主控能力: 应用上架分发(zip上传→发卡端商店浏览/下载)、站点授权管理(手动发放/封禁/删除)、在线购买(收银台支付成功自动生成永久激活码, 页面展示+邮件发送)、官方公告下发、收款设置(码支付多渠道勾选 + USDT)。
- 发卡端对接: 后台「系统设置→官方市场地址」填主控域名; 授权中心「在线开通」——跳转主控收银台完成支付后获得激活码, 回到授权中心粘贴激活。

## 十、常见问题

- **页面空白/报错**: 确认PHP≥7.4, 宝塔站点 → 设置 → PHP版本。
- **支付回调不成功**: 后台系统设置里把「网站地址」填为完整域名(https://...), 保证公网可访问回调地址。
- **USDT不到账**: 检查钱包地址是TRC20(T开头); 确认买家转账金额与页面显示完全一致; 配置了每分钟cron.php计划任务。
- **微信/支付宝提示验签失败**: 支付宝公钥/应用私钥填反了; 微信APIv3密钥或证书序列号填错。
- **极验弹窗不出现**: 检查Captcha ID/Key是否填反; 极验后台若设置了域名白名单需包含你的域名; 浏览器控制台确认 gt4.js 可访问。
- **商店无法下载远程应用**: 检查「系统设置→官方市场地址」是否可访问; 付费应用需先激活专业版。
