## 🚀 快速开始（宝塔面板）

**1. 建站** —— 宝塔 → 网站 → 添加站点：填域名，PHP 选 7.4+，创建 MySQL 数据库

**2. 上传** —— 发行包上传到站点根目录并解压（`index.php` 直接位于根级）

**3. 安装** —— 访问域名自动进入安装向导，照抄数据库信息、设置管理员账号

**4. 收藏后台入口** —— 安装完成页展示随机安全入口（形如 `admin_x7k9q2.php`），**只展示一次**
> 忘了入口？查看 `data/config.php` 中的 `YF_ADMIN_ENTRY`

**5. 安全收尾** —— 删除 `install.php`，Nginx 站点配置加入：

```nginx
location ^~ /data/ { deny all; }
```

**6. 配置计划任务**（重要）—— 宝塔 → 计划任务 → Shell 脚本，每 1 分钟：

```bash
php /www/wwwroot/你的站点目录/cron.php
```

> 作用：未支付订单超时自动关闭 + USDT 等链上到账轮询（买家支付页也会触发，cron 实时性更好）

<details>
<summary><b>🐳 Docker 部署（无需宝塔）</b></summary>

```bash
docker compose up -d --build
```

访问 `http://服务器IP:8080/install.php` 完成安装，数据库信息：地址 `db`、库名 `kunfaka`、用户 `kunfaka`、密码 `kunfaka123`

- 自带 cron 服务（订单过期 + 链上轮询），无需配置计划任务
- 配置与上传图片存于命名卷 `app_data` / `app_uploads`，升级镜像不丢失
- 改端口：编辑 `docker-compose.yml` 中 `"8080:80"` 左侧
- 生产建议：前置 Cloudflare 或 Nginx 反代做 HTTPS

</details>

## 🛡️ 安全设计

**人机验证（三选一，后台「系统设置 → 安全验证」配置）**

作用于前台注册、前台登录、后台登录、**下单购买**四道关口：

| 方式 | 说明 |
|---|---|
| 极验 GeeTest v4 | 页面内联「点击按钮开始验证」，一键通过自动提交；服务端 HMAC-SHA256 二次校验 |
| Cloudflare Turnstile | Cloudflare Dashboard 添加站点后填 Site Key / Secret Key |
| 图形验证码 | GD 生成，点击刷新，默认兜底 |

> 任一模式密钥不完整时自动降级为图形验证码，不会锁死登录。

**自动生效的防护**

| 防护项 | 规则 |
|---|---|
| 注册 IP 限制 | 同一 IP 每 24 小时最多注册 3 个账号 |
| 登录爆破锁定 | 同一账号+IP 一天错 5 次 → 锁 60 分钟；同 IP 累计错 ≥ 20 次同样锁定 |
| 下单频控 | 同一 IP 每小时下单数上限（后台可调），防恶意刷单 |
| 全站 CSRF | 所有后台与前台表单带令牌校验 |
| 支付安全 | 回调双重验签 + 金额一致性校验，订单号 64 位高熵随机不可枚举 |
| 商店安全 | 安装包 Zip Slip 防护、插件类名白名单、付费应用按域名加密分发 |
| 后台安全 | 随机安全入口、安装器防重装接管、uploads 禁止脚本执行、安全响应头 |

## 💎 专业版 & 应用商店

- 商店分**插件 / 主题**两个板块，应用分免费与付费
- **99 元专业版会员**：商店全部付费内容（含后续新增）免费畅享
- **付费应用加密分发**：经官方商店下载时按「站点域名 + 授权码」派生密钥动态加密打包，仅授权站点可解密运行，文件复制到其他站点无法使用。开源仓库因此不含付费应用源码，付费内容经官方应用商店分发
- 后台 → 授权中心：粘贴授权码激活（默认在线校验并绑定域名；离线激活需在 `data/config.php` 自定义 `YF_OFFLINE_SECRET`，配套工具 `tools/make_license.php`）

**设计理念**：发卡程序本体完全免费，核心功能（商品 / 卡密 / 订单 / 会员 / 支付 / 主题与应用商店机制）无任何限制；付费门控只存在于商店条目的 `pro / price` 字段，核心程序永远不加付费墙。

## ❓ 常见问题

<details>
<summary><b>页面空白 / 报错</b></summary>
确认 PHP ≥ 7.4；宝塔站点设置的 PHP 版本选择正确。
</details>

<details>
<summary><b>支付回调不成功</b></summary>
后台系统设置的「网站地址」填完整域名（https://...），保证公网可访问回调地址。
</details>

<details>
<summary><b>USDT 不到账</b></summary>
确认钱包地址是 TRC20（T 开头）；买家转账金额与页面显示完全一致；已配置每分钟 cron 计划任务。
</details>

<details>
<summary><b>微信 / 支付宝验签失败</b></summary>
检查支付宝公钥 / 应用私钥是否填反；微信 APIv3 密钥或证书序列号是否填错。
</details>

<details>
<summary><b>极验按钮不出现</b></summary>
检查 Captcha ID / Key 是否填反；极验后台域名白名单需包含你的域名；控制台确认 gt4.js 可访问。
</details>

<details>
<summary><b>商店无法下载应用</b></summary>
检查「系统设置 → 官方市场地址」是否可访问；付费应用需先激活专业版。
</details>

<details>
<summary><b>忘了后台入口</b></summary>
查看站点 <code>data/config.php</code> 中的 <code>YF_ADMIN_ENTRY</code>，对应文件名即后台入口。
</details>
