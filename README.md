## 这是什么

坤发卡是一套开箱即用的**全自动发卡系统**: 买家在你的网站选商品、扫码付款, 系统在支付成功的瞬间自动完成发货——卡密直接显示在买家屏幕上, 同时发送邮件副本。全程无需人工值守, 适合售卖游戏充值、账号租售、CDK 激活码、课程兑换等一切可自动交付的商品, 也支持实物邮寄(收件人/地址字段)。

内置应用商店: 支付插件与主题在线安装、在线升级; 付费应用按域名加密分发, 保护作者权益。

## 🚀 快速开始

### 宝塔面板(推荐)

1. **建站**: 宝塔 → 网站 → 添加站点(PHP 7.4+), 创建 MySQL 数据库
2. **上传**: 发行包解压到站点根目录, 访问域名进入安装向导
3. **收藏后台入口**: 安装完成页展示随机入口(形如 `admin_x7k9q2.php`), **只显示一次**
4. **安全收尾**: 删除 `install.php`, Nginx 加 `location ^~ /data/ { deny all; }`
5. **配置计划任务**(必配): 宝塔 → 计划任务, 每 1 分钟执行:

```bash
php /www/wwwroot/你的站点目录/cron.php
```

> cron 负责: 未支付订单超时关闭 + 加密币到账轮询。买家支付页也会触发, cron 实时性更佳。

### Docker

```bash
docker compose up -d --build
```

访问 `http://IP:8080/install.php` 完成安装。数据库: 地址 `db` / 库名 `kunfaka` / 用户 `kunfaka` / 密码 `kunfaka123`。自带 cron 服务与数据卷, 升级镜像不丢配置。

## ❓ 常见问题

<details>
<summary><b>忘了后台入口</b></summary>
查看 <code>data/config.php</code> 的 <code>YF_ADMIN_ENTRY</code>, 即后台入口文件名。
</details>

<details>
<summary><b>页面空白 / 报错</b></summary>
PHP ≥ 7.4, 宝塔站点 PHP 版本选择正确; 查看 PHP 错误日志定位。
</details>

<details>
<summary><b>USDT 不到账</b></summary>
TRC20 地址(T 开头) + 转账金额与页面完全一致 + 每分钟 cron 已配置, 三者缺一不可。
</details>

<details>
<summary><b>支付回调失败</b></summary>
系统设置「网站地址」填完整 https 域名, 确保公网可达回调地址。
</details>

<details>
<summary><b>人机验证不显示/不通过</b></summary>
极验 ID/Key 勿填反, 域名白名单需含站点域名(www 与 @ 建议都加); 密钥不全自动降级图形码。
</details>

<details>
<summary><b>能自己开发插件/主题吗</b></summary>
能。插件放 <code>plugins/</code>, 主题复制 <code>themes/store</code> 改样式, 商店机制自动识别。
</details>
