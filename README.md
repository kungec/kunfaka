## 🚀 快速开始（宝塔面板）

1. **宝塔 → 网站 → 添加站点**：填域名，PHP 选 7.4+，创建 MySQL 数据库并记下密码
2. **上传程序**：将发行包上传到站点根目录并解压（根目录下直接是 index.php）
3. **访问域名**：自动进入安装向导 → 照抄数据库信息 + 设置管理员账号密码 → 完成
4. **收藏后台地址**：安装完成页展示**随机安全入口**（形如 `admin_x7k9q2.php`），只展示一次请立即收藏
   - 忘了入口：查看 `data/config.php` 中的 `YF_ADMIN_ENTRY`
5. **安全收尾**：删除 `install.php`；Nginx 用户在站点配置加入：

```nginx
location ^~ /data/ { deny all; }
```

## ⏰ 计划任务（重要）

宝塔 → 计划任务 → Shell 脚本，每 1 分钟执行：

```bash
php /www/wwwroot/你的站点目录/cron.php
```

也可以用 URL 方式（密钥见 `data/config.php` 中的 `YF_KEY`）：

```bash
curl -s "http://你的域名/cron.php?key=你的YF_KEY值"
```

> 作用：① 未支付订单超时自动关闭；② USDT 等链上免挂支付到账轮询（买家支付页也会触发，计划任务实时性更好）。

## 🐳 Docker 部署（可选，无需宝塔）

```bash
docker compose up -d --build
```

访问 `http://服务器IP:8080/install.php` 完成安装向导，数据库信息填：

| 项 | 值 |
|---|---|
| 数据库地址 | `db` |
| 数据库名 | `kunfaka` |
| 用户名 | `kunfaka` |
| 密码 | `kunfaka123` |

**说明**

- 自带 cron 服务（订单过期 + 链上轮询），无需配置计划任务
- 配置与上传图片保存在命名卷 `app_data` / `app_uploads`，升级镜像不丢失
- 改端口：编辑 `docker-compose.yml` 中 `"8080:80"` 左侧端口
- 常用命令：`docker compose logs -f app` 查日志；`down` 停止（数据保留）
- 生产建议：前置 Cloudflare 或 Nginx 反代做 HTTPS 后再对外

## 🧭 老版本升级（v1.0.0 / v1.1.0 → v1.2.0）

浏览器访问一次 `http://你的域名/tools/upgrade.php`，自动补齐新表与新配置项（幂等安全），完成后删除该文件。全新安装无需此步骤。

- 后台「系统设置 → 客服联系方式」添加多条客服：Telegram / 邮箱 / QQ / 微信 / 电话 + 备注
- 前台右下角悬浮客服按钮：微信 / QQ 一键复制、TG 直达 t.me、邮箱 mailto、电话 tel；未配置不显示

### 系统日志与订单清理

- 「📜 操作日志」自动记录：管理员 / 会员登录、支付发货、USDT 到账、商店操作、清理动作，支持类型筛选
- 订单页一键清理：清理已过期 / 待支付订单 / 清空全部（均需确认，清理动作写日志留痕）

### 人机验证（三选一）

后台「系统设置 → 安全验证」配置，作用于：前台注册、前台登录、后台登录、**下单购买**

| 方式 | 说明 |
|---|---|
| 极验 GeeTest v4 | bind 模式一键通过体验；服务端 HMAC-SHA256 二次校验；验证有效期 10-600 秒可调 |
| Cloudflare Turnstile | Cloudflare Dashboard 添加站点后填 Site Key / Secret Key |
| 图形验证码 | GD 生成，点击刷新；为默认兜底方式 |

> 任一模式密钥填写不完整时自动降级为图形验证码，不会锁死登录。

### 安全限制（自动生效）

| 防护项 | 规则 |
|---|---|
| 注册 IP 限制 | 同一 IP 每 24 小时最多注册 **3** 个账号 |
| 登录爆破锁定 | 同一账号+IP 一天密码错 **5** 次 → 锁定 **60 分钟** |
| IP 轮换爆破兜底 | 同一 IP 60 分钟内累计错误 ≥ 20 次 → 锁定 60 分钟 |

### 安全设计

- 订单号高熵随机（64 位随机空间），无法枚举他人订单与卡密
- 全站表单 CSRF 防护；支付回调签名验证 + 金额一致性双重校验
- 计划任务 URL 方式需携带密钥（防外部随意触发）
- 应用商店安装包 Zip Slip 防护、插件类名白名单
- 安装器防重装接管；自动安全响应头
- 渗透测试覆盖：SQL 注入 / XSS / CSRF / 越权枚举 / 通知伪造 / 金额篡改 / 路径穿越等 32 项断言全部通过

## 💳 支付插件配置

后台 → 应用商店 → 插件 → 安装 / 启用 → 配置。支付页自动匹配品牌图标（微信 / 支付宝 / USDT / QQ 等）。

### 1. 码支付（易支付协议）

- 平台：[xpay.shw1.com](https://xpay.shw1.com/doc/epay_submit)（接口文档）
- 填写：网关（默认已填）、商户 ID（pid）、商户密钥（KEY）、支付渠道

### 2. 易支付

- 填写任意易支付平台的网关地址 / 商户 ID / 商户密钥

### 3. 支付宝当面付 / 支付宝官方

- [支付宝开放平台](https://open.alipay.com) 创建应用 → 签约「当面付」或「电脑网站支付」
- 填写：APPID、应用私钥（PKCS8）、支付宝公钥；回调地址系统自动生成

### 4. 微信官方支付（V3 Native 扫码）

- [微信支付商户平台](https://pay.weixin.qq.com) 开通 Native 支付产品
- 填写：商户号、APPID（需绑定商户号）、API 证书序列号、`apiclient_key.pem` 私钥内容、APIv3 密钥

### 5. 国际信用卡（Visa / Mastercard）

- [Stripe](https://stripe.com) 后台获取 API 密钥填入插件配置
- Webhook 异步通知 + 回跳二次核实双通道发货，HTTPS 强制证书校验

### 6. 加密币免挂支付 ⭐ 专业版专享

| 插件 | 配置 | 到账检测 |
|---|---|---|
| USDT 免挂支付（TRC20） | 只填 TRC20 钱包地址（T 开头） | TRON 公链公开接口 |
| USDT 多链（BEP20 / ERC20 / POLYGON） | 该链收款地址 + 区块浏览器免费 API 密钥 | Etherscan 系接口 |
| BTC / ETH / XMR | BTC/ETH 只填收款地址；XMR 需自建 monero-wallet-rpc | 各公链公开接口 |

> 原理：每笔订单分配唯一金额尾数（或按实时汇率换算），链上检测到账精准对账后自动发货。无需挂机、无需节点。

### 7. EPUSDT 自建网关 ⭐ 专业版专享

- 对接开源 USDT 支付网关 [EPUSDT](https://epusdt.com)（自部署）：填写网关地址 / 商户 PID / 商户密钥
- 买家跳转网关收银台按实时汇率支付 USDT，链上确认后自动回调发货，无需暴露钱包私钥

## ❓ 常见问题

<details>
<summary><b>页面空白 / 报错</b></summary>
确认 PHP ≥ 7.4；宝塔站点设置中 PHP 版本选择正确。
</details>

<details>
<summary><b>支付回调不成功</b></summary>
后台系统设置里把「网站地址」填为完整域名（https://...），保证公网可访问回调地址。
</details>

<details>
<summary><b>USDT 不到账</b></summary>
确认钱包地址是 TRC20（T 开头）；买家转账金额与页面显示完全一致；已配置每分钟 cron 计划任务。
</details>

<details>
<summary><b>微信 / 支付宝验签失败</b></summary>
支付宝公钥 / 应用私钥是否填反；微信 APIv3 密钥或证书序列号是否填错。
</details>

<details>
<summary><b>极验弹窗不出现</b></summary>
检查 Captcha ID / Key 是否填反；极验后台域名白名单需包含你的域名；控制台确认 gt4.js 可访问。
</details>

<details>
<summary><b>商店无法下载应用</b></summary>
检查「系统设置 → 官方市场地址」是否可访问；付费应用需先激活专业版。
</details>
